# gata throwaway UI prototype

Answers [issue #6](https://github.com/ChrisHorrocks/gata/issues/6): itinerary and kit screen layouts.

```bash
npm run dev
```

Open `http://localhost:5173/gata/#/prototype/itinerary` and use `?variant=` plus the bottom switcher (or arrow keys when not in an input).

Build for GitHub Pages uses `base: /gata/` and hash routing.
